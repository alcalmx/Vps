Qué necesita un host VMware para este flujo

Checklist de puesta en marcha: lo que debe tener un ESXi para que el motor pueda crear y gestionar VPS ahí. Cuando sumes un host nuevo, esto es lo que hay que dejarle listo. La columna alcance distingue lo que va en cada host de lo que se hace una sola vez (por SO/marca).

ComponenteQué es / para qué sirveDónde viveAlcance
Estructura de carpetasVPS/ _plantillas _papelera _bin El árbol donde el sistema crea, guarda plantillas y manda a papelera. Todo opera solo aquí dentro. Datastore del host por host
ISO de instalaciónAlmaLinux 9.x minimal Base para construir la dorada (con repos online para cloud-init + open-vm-tools). Solo se usa al fabricar la plantilla, no en cada VPS. Datastore (puede ser central) 1 vez / SO
Plantilla doradadorada-almalinux9.7 Imagen maestra de la que se clonan todos los VPS: AlmaLinux sellada con cloud-init, open-vm-tools, llave de gestión y sshd endurecido. El clon es local, por eso vive en cada host. _plantillas/ del host por host
Wrapper SSHvps-wrapper.sh Único punto de entrada SSH del motor al host. Whitelist de subcomandos (clonar, crecer, papelera) y valida que toda ruta esté bajo VPS/. _bin/ del host por host
Llave del wrapperen authorized_keys La pública del motor instalada con command= forzado al wrapper — sin shell libre aunque se filtre. authorized_keys de root del host por host
Usuario API + rolsvc-vps · VpsOperator Cuenta con permisos mínimos de VM para la API (crear/config/power/registrar). Sin acceso de host ni root. El motor nunca usa root. ESXi / vCenter por host
Portgroup de la red VPS El grupo de puertos que transporta la VLAN donde viven los VPS. Producción: 10.100.16.0/24 (Vps Hosting). Red del host (vSwitch) por host
Conectividad y salida El host debe alcanzar la red de los VPS y el MikroTik (IP libre + NAT). Los VPS necesitan salida a internet para cPanel y la securización (en producción, vía el NAT de su IP pública). Cableado / VLAN / NAT por host
Recursos suficientes CPU, RAM y disco libres en el datastore para los sabores que se creen (ej. Cyber Black = 6 vCPU / 8 GB / 150 GB). Hardware del host por host
